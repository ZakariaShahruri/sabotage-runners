## 🎮 About the Game
**Sabotage Runners** is a fast-paced, chaotic 1v1 local multiplayer game built entirely from scratch in Python using Pygame. 

The objective is simple: **Race to your opponent's spawn point to score.** The first player to reach 3 points wins the game. However, the arena is filled with randomly spawning power-ups. Strategy and timing are key as you decide whether to grab an item to boost your own speed or ruthlessly sabotage your opponent!

## ✨ Features
* **1v1 Local Multiplayer:** Grab a friend and share a keyboard for intense head-to-head action.
* **Dynamic Items & Power-ups:** Turn the tide of the game with randomly spawning items:
  * 🧊 **Freeze:** Stop your opponent dead in their tracks.
  * 🐢 **Slow Down:** Slash your opponent's movement speed.
  * 🔄 **Mirror:** Reverse your opponent's controls for maximum confusion.
  * ⚡ **Speed Up:** Gain a massive burst of speed to cross the map.
  * 🌌 **Teleport:** Instantly send your opponent all the way back to their spawn.
* **Combat Mechanics:** Attack your opponent to apply knockback and gain the upper hand.
* **Multiple Arenas:** Battle across different maps with unique layouts and platform arrangements.
* **Custom Assets:** Fully animated player sprites, custom UI, and original audio/music integration.

## ⌨️ Controls

| Action | Player 1 | Player 2 |
| :--- | :---: | :---: |
| **Move Up** | `W` | `Up Arrow` |
| **Move Left** | `A` | `Left Arrow` |
| **Move Down** | `S` | `Down Arrow` |
| **Move Right** | `D` | `Right Arrow` |
| **Attack / Knockback**| `Q` | `Right Shift` |

## 🚀 Installation & How to Play

1. **Clone the repository:**
   ```bash
   git clone https://github.com/yourusername/sabotage-runners.git
   cd sabotage-runners
   ```

2. **Install dependencies:**
   Ensure you have Python 3 installed, then install Pygame:
   ```bash
   pip install pygame
   ```

3. **Run the game:**
   ```bash
   python scripts/main.py
   ```
